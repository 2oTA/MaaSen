# 🌲 MaaSen 公告功能测试

这是一篇**测试公告**，用来验证公告功能是否正常工作。确认能弹窗显示后，把它删掉或替换成正式内容即可。

## 当前已实现功能

- ✅ **进入游戏**：桌面找图标 → 等待加载 → 识别点击「进入森林」→ 自动关闭弹窗广告 → 点击主界面入口
- ✅ **居中视野**：捏合缩放到最小 + 两段拖动自动居中，每次进入后视角一致

## 使用方法

1. 前往 [Releases](https://github.com/2oTA/MaaSen/releases) 下载最新版本 zip
2. 解压后双击运行，界面由通用 UI（MFAAvalonia）提供
3. 连接安卓设备 / 模拟器（需开启 ADB），选择「安卓端」控制器
4. 勾选「进入游戏」任务，点击开始
