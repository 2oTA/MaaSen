# 农田地块数据

游戏内共有 6 块可种植地块，本文记录其位置，供后续「种植 / 浇水 / 采花」等操作使用。

## 坐标说明

- 「原始坐标」按模拟器截图上的像素记录，当前 MuMu 实例分辨率为 **900×1600**
- 本项目控制器配置 `display_short_side: 720`，MaaFramework 内部使用 **720×1280** 坐标系（9:16），因此 pipeline 中要写的是 **原始坐标 × 0.8**
- 若之后换了模拟器分辨率（如 1080×1920），换算比例改为 `720 ÷ 屏幕宽度`，不要直接套用下表的 720 数值

## 后续接入方式（待实现）

种植、浇水、采花等操作目前尚未实现，计划按以下结构与 ProjectInterface 配合：

1. 每个「操作 × 地块」组合定义一个 pipeline 节点，例如 `Plant_Plot1` … `Plant_Plot6`，`target` 指向该地块中心，并默认 `enabled: false`
2. 每种操作有一个入口节点，`next` 按 1→6 顺序列出 6 个地块节点；未启用的节点会被框架自动跳过
3. `interface.json` 中用 `checkbox` 类型的选项让用户勾选地块，每个 case 的 `pipeline_override` 把对应节点 `enabled` 改成 `true`

示意：

```jsonc
{
    "Plant_Plot1": {
        "enabled": false,
        "recognition": "DirectHit",
        "action": "Click",
        "target": [341, 641]
    }
}
```

```jsonc
{
    "种植地块": {
        "type": "checkbox",
        "cases": [
            {
                "name": "地块1",
                "pipeline_override": {
                    "Plant_Plot1": {
                        "enabled": true
                    }
                }
            }
        ]
    }
}
```

## 验证方法

实现点击动作后，可先用一个临时节点依次点击 6 个地块中心，确认落点都在田块内、且不会点到相邻地块或界面按钮。
